ЧТО ИСПРАВЛЕНО В ЭТОЙ ВЕРСИИ
-------------------------------------------------------------------
1. Приложение больше НЕ требует, чтобы на компьютере пользователя (боссы)
   был установлен Node.js - раньше оно пыталось вызвать системную команду
   "node", которой у неё просто не было. Теперь используется Node,
   встроенный прямо в сам Electron (тот же движок, на котором работает
   всё приложение) - то есть ничего ставить не нужно вообще.
2. build-print-pdf.py (Python) полностью заменён на build-print-pdf.js
   (Node) - та же логика, тот же результат, но без Python.
3. Шаг "Inspector" (qa-validate.py) временно ОТКЛЮЧЁН - это был
   последний кусок, всё ещё зависящий от Python. Он не блокировал
   создание презентации и раньше (был не обязательным), так что сейчас
   просто пропускается молча, без предупреждений. Когда пришлёшь мне
   исходник qa-validate.py - перенесу и его на Node, и включим обратно.
4. Порядок слайдов Game 2 (сразу после Game 1) и Game 3 (после Pattern
   Sheet), увеличенный Pattern Sheet, отступы на Game 1/2/3, новый экран
   загрузки, фикс градиентов созвездия, 3 раунда вместо 3-4 в чантах -
   всё это уже было отправлено раньше, для полноты картины включено в
   этот же архив.


ШАГИ - ЧТО ДЕЛАТЬ
-------------------------------------------------------------------
1. Распаковать архив ПРЯМО В корень проекта (E:\Cloude\StarTeam\),
   подтвердить замену файлов.
   (Опционально: удалить старый engine\scripts\build-print-pdf.py -
   он больше не нужен, но и не мешает, если оставить.)

2. Открыть терминал в папке проекта и выполнить:

       npm install

   Это обязательно - появилась новая зависимость (pdfkit), без неё
   PDF-скрипт не соберётся.

3. Собрать:

       npm run build

4. Проверить у себя: создать презентацию, убедиться что PPTX и
   печатный PDF создаются без ошибок про "node"/"python" не
   распознан.

5. Если всё ок - релиз на GitHub:
   - Тег: v1.6.8
   - Файлы из dist\: Star-Team-Setup-1.6.8.exe, latest.yml,
     Star-Team-Setup-1.6.8.exe.blockmap - ВСЕ ТРИ ИЗ ОДНОЙ СБОРКИ,
     залить одновременно
   - Publish

6. Дальше ничего специально боссе отправлять не нужно - у неё уже
   стоит более старая версия с автообновлением. Как только релиз
   опубликован, при следующем запуске (или через Settings -> Check
   for updates) её приложение само найдёт и скачает 1.6.8, ей
   останется только нажать "click here to restart and install".
   Ей не нужно ничего скачивать/устанавливать вручную кроме этого.
